# Anim Recipes — 代码动画配方（机制演示，按需件）

> **与 CSS 动画库的分工**：effects 模块挂类名即生效（入场/图表生长/数字滚动），全 deck 预置；
> 代码动画是**逐页手写的机制演示**（管线生长/参数联动…），过三问闸门才写，配额限量。
> 生命周期不用自己管——底盘 `anim-runtime.js` 已内置：进场起播/翻回重播/切页停/reduced 终态/打印定格/时长硬顶 4s。

## 一、三问闸门（大纲"过程/机制/因果"页先过闸，任一不过 → 走 diagram-patterns 静态图示）

1. 这页讲的是**过程 / 机制 / 因果 / 随参数变化**吗？
2. 静态图示 + 一句话**表达不了**吗？
3. 动起来**能看到变化规律**吗（不只是好看）？

**反触发**：纯数据→图表；纯层级/交集→图示；纯观点→提炼；该页已有独立动画焦点→不做。

## 二、配额与密度闸（阶段 3 预标注时算，阶段 4 大纲执行）

| 内容页数（不含封面/结束页） | 默认上限 | 可上调（需闸门页数量够 + 用户明说"这几页要讲清机制"） |
|---|---|---|
| ≤6 | 1 | 2 |
| 7–10 | 2 | 3 |
| 11–15 | 3 | 4 |
| 16–30 | 3 | 4（封顶） |

- **间距 ≥2 页**：两个动画页之间至少隔 2 页非动画页
- **视觉重页 ≤50%**：动画+图示+图表+全出血深色页 ≤ 内容页一半
- **收敛规则联动**（animation-routing 三层收敛）：命中正式汇报/打印分发/文字型信号 → 代码动画配额**归零**（最贵可视化第一个砍），机制页转静态图示

## 三、落点与属性契约（v2 舞台坐标 1920×1080，直接量无需换算）

| 类名/属性 | 含义 |
|---|---|
| `.anim-slot` | 动画焦点槽（body-area 内），高度 ≤380px |
| `.anim-canvas` / `.anim-svg` | 渲染载体二选一 |
| `data-anim-kind="pipeline\|stack\|converge\|curve\|param"` | 五配方标识 |
| `data-anim-recipe="R-1"` | 能力标识（统计/计费预留） |
| `data-anim-dur="2000"` | 声明总时长 ms（runtime 硬顶 4000） |
| `data-anim-formula="s=½gt²"` | 教学向必标公式原文 |

**纪律**：动画槽**不挂 `.rv`**（v1 时代"整块上飞"事故的 v2 等价解——入场动画与机制动画叠加会打架）；单页一个动画焦点；同页可与 step 叙事共存（最后一个 step 触发也可，动画照样 slide:enter 起播）。

## 四、生成端写法（注册制，两段完事）

```js
// 页面元素：<div class="anim-slot"><canvas class="anim-canvas" width="1100" height="360"></canvas></div>
__anim('p7', function () {
  var cv = document.querySelector('#p7 .anim-canvas');
  var ctx = cv.getContext('2d');
  var segs = 4;                                    // 例：管线 4 段
  function draw(k) {                               /* 按 k∈[0,1] 画到 k 进度 */ }
  return {
    step: function (t) { draw(t); },
    final: function () { draw(1); }                // 终态：完整机制图（打印/截图/PDF 就是它）
  };
}, { dur: 1900, delay: 300 });
```

- 绘制逻辑按第五节配方骨架写；**canvas DPR**：`cv.width = cssW * devicePixelRatio; ctx.scale(dpr, dpr)`
- **点击重播（可选）**：`cv.addEventListener('click', function(e){ e.stopPropagation(); /* 重播：翻出再翻回，或自行调局部逻辑 */ })`
- **数值纪律（命门）**：动画里的数字标签**必须由公式算出**（例：落体 `s = 0.5*g*t*t`，标签读变量），**禁止手写**；单位/有效位与素材一致；公式进代码注释 + `data-anim-formula`

## 五、五配方骨架

| 配方 | 表达 | 建议时长 | 终态 |
|---|---|---|---|
| R-1 流程生长 | 管线逐段绘出、节点依次点亮 | 1.2–1.8s | 完整管线 |
| R-2 层级堆叠 | 横条自下而上叠起 | 1.8–2.5s | 全层完成 |
| R-3 汇聚/辐射 | 节点向核心收拢/散开 | 1.8–2.5s | 静态辐射图 |
| R-4 曲线绘出 | 折线逐点生长 + 末值跟随 | 2.5–3.5s | 完整曲线 |
| R-5 参数联动 | 变量循环取值驱动图形（教学王牌） | 2.5–3.5s | 三个时刻并置 |

**机制签名（每页 ≥2 个才算内容动画）**：线条生长（stroke/lineTo 随 t）/ 遮罩揭示 / 数值跟随 / 位置迁移 / 组件生长 / 参数驱动重绘 / 节点依次点亮。
**filler（不算机制）**：纯 opacity 过渡、呼吸、脉冲、装饰粒子——只用淡入凑数过不了闸。

## 六、验收（阶段 6.5）

- 源码自查：配额/间距/重页占比/属性契约/数值纪律（无手写标签）
- 机验（有 playwright 时）：起播→1s 截图→5s+500ms 双截 hash 一致（停播）；reduced 重载 == 终态；槽 bbox 进页前后 dy ≤2px
- **别为过闸加动画**：缺的是内容，不是动效
