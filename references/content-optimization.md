# 内容优化原则

> 本文件包含阶段3的10条优化原则（3.1~3.8，含 3.7b、3.7c），用于素材到大纲之间的静默优化。

**3.1 聚焦即说不** — 砍掉「听众已经知道的」和「说了等于没说的」。判断标准：砍掉后听众理解会受损吗？不会 → 砍。

**3.2 一句话定义** — 每页能否用一句话（≤15字）说清核心信息？不能 → 内容杂糅，需拆分或聚焦。（口径分工：本条 15 字管"核心信息概括"；**页标题字数执行 ≤22 字，类型按体裁档位定**——A 纯书面 / B 汇报+现场讲 / C 纯演讲，三档配比与判据见 [title-copy-types.md](title-copy-types.md)；B、C 档的钩子句同样受 ≤22 字约束且必须配副行数据注。字号与密度档按 [layout-rules-v2.md](layout-rules-v2.md) §2.2-§2.3——两者同名不同物，不冲突）

**3.3 三的法则** — 一页超过3个要点 → 合并为3组或拆页。主体分为3个大章节（起因→做法→成果 / 问题→方案→效果 / 过去→现在→未来）。

**3.4 先结论后铺垫** — 默认结论/数据亮点在前、展开解释在后；例外 = 过程型叙事（从过程往上涨）时结论压轴、`.step` 最后弹——与 SKILL 核心原则 5（焦点唯一性前置判定）同口径。

**3.5 做减法** — 超出一页承载量的内容 → 拆为两页、提炼核心数据、用图表替代文字。

**3.6 数据与故事交汇** — 纯数据页加故事线，纯叙述页加数据支撑。

**3.7 焦点识别** — 每页必须有一个核心焦点（一个数字、一个结论、一张关键图表）。判断方法：如果这页删掉任何一个元素都不影响理解，说明没有焦点。识别出焦点后，**焦点决定布局，不是布局决定焦点**：

| 焦点类型 | v2 槽位（按槽位判定树） | 排版原则 |
|---------|---------|---------|
| 一个关键数字（如71.7%、$1M） | **焦点数字槽**（`.hero-num` + `.hero-cap`，裸排无盒） | 数字 140-176px（`--fs-num-hero`），主从纵排贴身；**禁垫色块/彩色底**（focus-judgment 红线①、number-typography R1.1）；单位缩小挂尾 |
| 一个关键结论/对比 | **仪式位**（`.ritual` + `.quote-line`）或 **双栏对比**（`.duo`） | 字号走闭环反推（`--fs-quote` 140 / 长行档 112），居中仅仪式位；**禁 max-width 防溢钳制**（layout-rules §2.4） |
| 一张关键图表 | **图表槽**（`.chart` + `.footmark` 来源脚） | 图表占主体（380 高容器），一图一结论；结论写页标题，option 不设 title |
| 无明确焦点 · 论述页（本该有结论，却没提炼出来） | 禁止直接落槽位 → **回炉提炼**：转结论句 / 关键数字 / 关键图表，再选槽位 | 提炼不出焦点 = 这页没写完 |
| 无明确焦点 · 清单页（议程、名单、政策条目、参数表——本身无焦点） | **行组**（`.row`）/ **metric 组**（`.metric`）/ **表格** / 清单≥4 条优先转图示（diagram-patterns G 系列） | ≥4 条条目禁止单列纵排；单列纵排只准 ≤3 条 |

**论述 vs 清单的判定**：删掉其中任意一条，这页的论证还成立吗？成立 → 清单页；不成立 → 论述页，必须提炼焦点。
**反模式**：用"文字密集、不需视觉化"当理由落单列纵排——该理由已作废（原 L-4 适用说明已随 v1 布局库移出）。

**核心反模式：** 把焦点数字塞进 4 等分卡片横排（`.card-row`）里，和普通信息平起平坐。焦点数字必须是页面的视觉锚点，其他元素围绕它展开。

**3.7c 结构图示升级（结构焦点）** — 清单页 ≥4 条纯文字条目、且条目之间存在关系（先后/包含/对立/辐射/收敛）时，大纲展示时标注「建议升级结构图示」交用户确认（不强制改写）：
- 有数据 → 图表路由（选型见 chart-recipes）；依次/阶段 → G-01 管线；层级/依赖 → G-02 分层栈；两维度 → G-03 矩阵；时序 → G-04 时间线；一核心 N 并行 → G-05 辐射；选型对比 → G-06 对比表；逐级收敛 → G-07 漏斗；外护内 → G-08 同心环；交集 → G-09 韦恩
- 判据（加图前必过）：删掉这个图，读者会丢文字补不回来的信息吗？——不会就不加图（真源 diagram-patterns 首行）
- 无关系结构的清单（纯名单/参数表）不升级，走行组 / metric / 表格兜底

**3.7b 内容层级分析** — 焦点识别之后、布局和动画之前，必须先分析每页的内容层级结构。层级关系同时决定动画方式（3.8）和视觉呈现（阶段 6 槽位判定树）。

**分析方法：** 列出页面所有元素，判断它们之间是并列关系还是上下层级关系：
- **并列关系**：三张对比卡片、四个数据指标、五个建议条目 → 同层级
- **上下层级**：焦点数字 vs 支撑信息、并列内容 vs 总结结论 → 不同层级

**输出格式（每页一行）：**
```
P10 软件工程
  层级1（焦点）：71.7% → .step.impact（结论先行）
  层级2（支撑）：缺陷检测 / 智能辅导 / 端到端 → .step 逐条展开

P12 多智能体协作协议
  层级1（并列）：MCP / ACP / A2A → .rv 自动入场（同层级，--d 编排）
  层级2（结论）："三大协议互补而非竞争" → .step 点击出现

P14 核心结论
  层级1（并列）：三条结论 → .step 逐条点击（每条都是独立结论，需要独立呈现）

P5 智能体核心构成
  层级1（并列）：规划 / 记忆 / 工具 / 反思 → .rv 自动入场
  层级2（总结）："四要素缺一不可" → .step 点击出现
```

**判断规则：**
- 同一信息的不同方面（如三个协议各自的特点） → 并列 → .rv 自动入场
- 从细节到总结（如三个协议 → 互补结论） → 上下层级 → .step
- 焦点数字与其支撑证据 → 上下层级 → .step.impact + .step
- 独立结论列表（如三条核心结论） → 每条独立呈现 → .step（不是 .rv，因为每条需要观众单独消化）
- **视觉层级区分**：不同层级用不同视觉处理，判断标准是**内容量**，不是固定二选一：
  - **多项同层级内容** → 行组/双栏（发丝线分组优先；卡片仅身份独立并列块 ≤3，见 focus-judgment §二「结构辅助·卡片四场景」）
  - **单项内容，有实质内容量**（一个标题+多段文字、一段较长文字、图表等） → 独立视觉块，容器从轻（发丝线优先于盒）
  - **单项内容，只有一句话或一个标题**（如并列展示后的一句结论） → 用裸文字+更大字号+居中，不用容器
  - 两者可以共存于同一页：块层级和裸文字层级搭配使用，由内容量决定

**3.8 叙事节拍** — 基于层级分析结果标注动画，不是凭感觉：
- **层级跳跃 + 视觉冲击** — 加 `class="step impact"`，结论先行。用于焦点数字（71.7%、$1M）先弹出，支撑信息随后展开
- **层级跳跃** — 加 `class="step"`，从一层内容跳到更高层。用于：支撑信息逐条展开；并列内容展示完后结论点击出现
- **同层级并列** — 不加 step，用默认 `.rv` 分层自动入场（--d 依次编排）。用于：三组对比行、四个数据指标、五个建议条目
- **判断标准**：这些元素是并列关系还是上下层级？并列 → .rv 自动入场；上下层级 → .step 点击入场。**并列的特例——独立结论列表**（每条都是独立结论、需观众单独消化的结论+数字条目）→ .step 逐条，不是 .rv
- **使用频率**：10页PPT中，约2-3页需要 .step（有焦点数据的页、结论页），其余页面用默认入场动画

## 附：整页改写示例（文字提炼，2026-10-19）

**原文（≈240 字，典型"文字多"页）：**

> 当前大模型落地面临多重挑战。在算力方面，推理成本随调用量线性上涨，大促期间峰值扩容费用可达日常的 3.7 倍，而缓存命中率仅为 41%，低于行业基准 65%，每年因此多支出约 280 万元。在幻觉方面，金融合规场景实测开放式问答幻觉率为 8.3%，即使叠加 RAG 仍残留 2.1%，法务部门要求关键结论必须可溯源，导致 60% 候选场景被搁置。在数据方面，用户纠错数据分散在 4 个业务系统，缺乏统一回流管道，模型迭代周期被拉长至 11 周，而竞品平均仅 5 周。

**改写后（演示版；标题为结论句，三条独立结论逐条 .step，全稿进备注）：**

- 页标题（结论句，18 字）：`成本幻觉数据三线恶化，年多支 280 万`
- 三条 step（每条 = 结论 + 数字，金句级 32px 压轴行排版）：
  1. `算力成本失控 — 每年多支出 280 万`
  2. `幻觉率制约落地 — 60% 场景被搁置`
  3. `数据回流断点 — 迭代 11 周 vs 竞品 5 周`
- 来源脚（≤14 字）：`来源：2026Q3 运营复盘`
- NOTES（键=本页 id）：存原文 240 字全稿

> 注意：标题必须是结论句（含数字），不是「三大落地风险」这类主题标签——标签式标题=该页未完成。
