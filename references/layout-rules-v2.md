## 第〇层：体系总纲

**版面率管"有没有站住版面"，字号管"站住了看不看得见"，秩序管"看见了乱不乱"。下层不达标，上层免谈。**

```
第一层 底盘：版面率（空间关系：占多少、主角撑不撑得住、平不平衡）
第二层 阅读：字号（1/50 地板 + 密度-字号三元表 + 标题三层身份）
第三层 秩序：分组/对齐/间距（容器阶梯 + 档位层级树 + 平衡律）
```

## 第一层 底盘：版面率

### 1.1 版面率是第一裁决轴【经验+实测】
- 字号体验因人而异，版面空/满是客观几何量——评判排版优劣统一看版面率是否落进区间，字号/布局/容器都是伺服手段
- 闭环模型：先定版面区间 → 手段反推（不是"查表定字号"的开环）
- 上限与 overflow 探针咬合：超上限 ≈ 溢出前兆，处置同一律——**删内容不缩字**

### 1.2 版率口径与分带【实测+观察】
- 口径：内容文本包围盒 / 版面（剔除边注四件套；探针强制 opacity 防动画初始态骗检）
- 分带（机验红线）：

| 页型 | 红线 | 锚点 |
|---|---|---|
| 行组密排页 | 面积 ≥60% 且宽 ≥80% | 实测 75% 一档锁死 |
| 双栏短内容页 | 面积 ≥45% | WB 同型 36-40% 且观感良好 |
| 单焦点页（金句/焦点数字/封面） | 主角块宽 ≥60% 版心 | 金句一 140px×7字=60%【验证】 |

- 分带数值【待校准】：待同题实测数据校准

### 1.2b 欠填口径（vacuum 带探针，2026-10-22 立·阈值人判）
- **机验指标**（measure-layout.js）：页高垂直切 10 带，占带集合 = 文本叶子（同 §1.2 口径，剔边注四件套）+ img/canvas/svg（ECharts 渲 canvas 无 DOM 文本，不纳入则图表页必误报）；输出 vacMax（最大连续空带）/ vacBottom（底部连续空带）
- **判定**：**vacBottom ≥4（底 40% 无内容）→ 先查页型**——密排/双栏页 = 欠填，回 §1.3 白名单手段调；**单焦点页（金句/焦点数字/封面）豁免**（§1.4 留白配主角，居中留白合法）；vacMax 供中部断崖参考（任何页型 vacMax≥4 都值得肉眼复核）
- **只提示不 FAIL**：阈值待实测校准（与 §待校准条目同节奏）——治"overflow 只测溢出不测欠填"的实测病（下半 40-50% 纯黑空而探针全过）

### 1.3 反噬防火墙【经验（两轮反噬史）】
版率不达标时，允许的手段**只有白名单**：换纵向布局 / 升字号 / 换轻容器 / 砍页并页。
**永远禁止**：加图标、加数据条、加密卡片、拉大 gap 凑数。
> 60% 占位率下限反噬史（2026-10-15 两轮可视化填补）——规则数值可以变，此防火墙永不变。

### 1.4 留白配主角【经验+验证】
- 留白是主角的留白：大留白必须配大主角，主角小了留白就是空版
- 金句页 28px/25% 版心宽 = 空版负样本；140px/60% = 达标【验证】

### 1.5 平衡律（两个粒度）【经验】
- **组 vs 版心**：宽度不拉满的内容组禁全左钉 → 版心居中或配重（贴角小注可配平左上标题重心）；左轴只给横向拉满的密排内容
- **组内两翼**：横排本质是两翼配重——两翼墨迹高度比落在 0.5-1 带内才合法（【待校准】阈值）；轻文本（<0.3）横排必倒
- 居中是仪式位特权；内容页一页一左轴

## 第二层 阅读：字号

### 2.1 字号地板【实测（四包铁证）】
- 正文 ≥1/50 屏高（1080 舞台 = 21.6px → 实操 **22px**）
- meta 档 14-16px；边注/页码装饰 12-13px 豁免（FLOOR CARVE-OUT，写进探针排除清单）
- 署名 8.4px、卡字 12px（1/61 屏高）= 负样本【实测】

### 2.2 密度-字号-版率三元表【实测+经验】

| 密度档 | 判定（正文字数/页） | 正文 | 行组小标题 | 压轴行 | 版率手段（白名单内） |
|---|---|---|---|---|---|
| 低密度 ≤40 字 | 金句/焦点数字/收尾 | 24px | — | — | 字号补偿：主角 110-140px |
| 中密度 40-120 字 | 3-4 行组/双栏 | 24px | 30px | 32px | 行组纵向拉满全宽，目标 60%+ |
| 高密度 120-200 字 | 5 行+/表格/多列 | 22px（触地板） | 28px | 30px | 行距 24→20、组内压档，仍守分带下限 |
| 超密度 >200 字 | — | **禁止：砍字或砍页** | — | — | cut never compress |

- 场景轴（演讲/阅读）与内容轴（密度档）正交：阅读型+高密合法；**演讲型+超密=砍**
- **阅读型+高密观察档 66**（2026-10-21 挂 + 同日维护者感官裁决）：内容页标题 66px 仅限**阅读型（异步看屏）高密**内容页试用；**演讲型/现场投影一律 84 起步**。裁决依据：同内容、同版率 75% 的 A/B 对照中 66 vs 84 静态差异不大，但现场演示场景 84 阅读更清晰；66/22=3.0 仍低于 3.8:1 红线，故不升正式档、保持观察

### 2.3 标题三层身份与锁档【经验（维护者两次校正）】

| 身份 | 例子 | 字号规则 |
|---|---|---|
| 主张型（结论断言） | "内卷的尽头是微雕" | **全片锁死 84px（±0）**——脊柱一致性 |
| 话题型（描述容器） | "和难处相处的四种姿态" | 密度带内调 72-96，**同密度档内 ±0** |
| 焦点页标题 | "十年 60 秒"配 3652 | **唯一焦点判定**：标题当主角升档 / 数字金句当主角则标题退档，互斥 |

- 锁档单位 = 密度档（不是全片一刀切，也绝不允许同密度乱跳——69-173px 断层即此病【实测】）
- 标题带：下限 72px（3.3:1 @22px 正文，对比红线最后防线）/ 标准档 84px（WB 实测）/ 上限 96px（低密度补偿，内容区 ≥55% 版高拦住）
- 标题:正文锁定 3.8:1-5:1（低于 2.5:1 被否【经验】）

### 2.4 仪式位闭环反推【验证】
- 封面/金句/收尾主角字号 = 目标占版宽（60-85% 版心）÷ 行字数
- 实测演示：金句一 7 字/行→140px（60%）；金句二 12 字/行→112px（82%）
- **禁 max-width 防溢钳制**（旧金句页 60% 钳制导致 25% 版心病）——正解是反推字号，不是钳宽度

## 第三层 秩序：分组、对齐、间距

### 3.1 容器重量阶梯【经验】
- 盒装卡 > 线（发丝线 / 顶线卡）> 留白，**选最轻够用的**——顶线卡（border-top 2px，底盘 `.card`）是**线档**的组标识形态，说「卡」默认指它；盒装（`.card-box`）仅品牌预设点名
- **默认无盒禁令（2026-10-22 立，举证反转）**：文字/数据默认行组、发丝线组、裸排起手；凡写出一个卡片必须自证属于四场景之一（身份独立并列 / 引用切出 / 选择性突出 / 异构视觉单元并列，穷举表 → focus-judgment §二「结构辅助·卡片四场景」）——**说不出 = 撤盒**。治"一见数据就套卡、一见文字就套卡"两个默认病根
- 盒装卡只给品牌预设点名场景（≤3 张；一页 ≤1 hero + ≤3 quiet，hairlines over boxes）
- 文字量均等时留白即可分组+对齐；要对齐锚用线
- 距离是比盒子更强的分组信号：容器分了层级而间距没分 = 等于没分
> 卡片四场景穷举 + R1/R2/R3 卡形态（底盘 `.card` 组件）→ [focus-judgment.md](focus-judgment.md) §二「结构辅助·卡片四场景」（2026-10-22 判定链方案收敛）

### 3.2 线的两种身份【经验（封面挑刺）】

| 身份 | 例子 | 间距 |
|---|---|---|
| 引导线（元素附件） | 封面标题下短线 | 组内档 16-24px 紧贴——48px 的引导线=断线 |
| 分隔线（组间结构） | 行组 border-top | 组间位置，承担分组 |

### 3.2b 小标题标记（内容组级扫读锚，2026-10-22 立）

**序列判定先行（维护者裁定）**：内容有序列关系（步骤/流程/排名/优先级）→ 行组编号（`.no`）；非序列（并列论点/特性）→ 可用标记（`.sh-mark` 系，底盘组件）。**二选一，禁双前缀**（`01 ▍标题` = 锚点冗余 = 违规）。

- **与页面级 kicker 二分**：kicker 管页面级（每页 head 一个），sh-mark 管内容组级（页内条目小标题、清单条目、卡内标题）
- **同 deck 默认同形，同页强制**：形态跟池选型（下表），deck 内默认一种；与正文 bullet **两级不同形**（小标题=实心块 → bullet 用空心框/字符，反之亦然）
- **形态按池**：字符 glyph（`.dash`）→ 科技签名预设（Terminal Green / MongoDB / 8-Bit Orbit）；几何形（默认实心竖块 / `.hollow` 空心框）→ A1/A2 暗色与 B2 清爽现代；色点（`.dot`）→ B1 纸感编辑（暖）
- **尺寸/颜色**：几何形 0.5-0.7em 见方、字符 0.8em 等重；颜色 accent（默认）或 ink-dim（`.dim`）二选一，同 deck 统一；**emoji 永久禁**
- **位置跟版式轴**：左轴版式 → 标记左置水平排（`.sh-mark`，挂小标题元素）；中轴/居中版式 → 标记上置、标记—标题—正文共中轴垂直堆叠（`.sh-mark-top`）；标记永远锚在版式轴上，禁悬空、禁斜插

### 3.3 间距档位 = 层级树【经验（p5 挑刺）】
- **N 层结构 N 档间距**，常见三档：板块间 64-72px（+分隔线）/ 组间 28-32px / 条目间 14-18px
- 相邻档比 ≥2:1；同层必须同档；**禁等距分布**（同一容器内全等间距=无分组=违规，可机验）
- **gap 管亲疏，padding 管呼吸**：占版率拉条目自身 padding，永不拉 gap——拉 gap 是把关系当填料

### 3.4 主从二式【经验+校正】
- 从属轻（单行标签/图注，与大元素高度比 <0.3）→ **纵排贴身**（组内间距）
- 从属重（3-4 行成块，高度比 0.5-1）→ **横排两翼**（48-72px，配重平衡）
- 层级关系横排给轻文本 = 语义错位 + 视觉失衡双重违规

### 3.5 对齐分层【经验】
- 组内轴：同轴元素 X 极差 ≤2px（机验已有）
- 版心平衡：见 1.5；光学居中允许 1-3px 微调（豁免于 X 极差）
- 垂直居中缩团 = 版率杀手，内容分布必须铺满（flex 均分/space-between，禁 justify-content:center 当布局手段）

### 3.6 信息三归宿【经验】
- 内容流中轴：主角/主体/压轴行（梯队制：标题 84 → 压轴 32 → 小标题 30 → 正文 24 → meta 16）
- 轴上小字：要读不重的落款（16px 灰）
- 角落位：可忽略信息（备注/来源/页码）退出内容轴，贴左下/右下/右上皮屑位；纯装饰可低于地板（豁免），要读的不豁免
- 压轴行两种形态：金句级收束用 A 案（24-26px 字重 600 左轴）；普通收束用 B 案（16px 灰）；内容定形态，不一刀切

## 体系定位：上下游关系

- **上游**：底盘思路与部分风格体系继承自 [Frontend Slides](https://github.com/zarazhangrui/frontend-slides)（MIT，声明见 SKILL.md 文末《来源与许可》）——8-Bit Orbit / Broadside / Capsule 三套预设由该库移植，卡片形态 R1/R2/R3 由其蒸馏而来。v2 范式（三层规则 + 七阶段 + 机验闭环）为本包重写。
- **下游**：产出是单文件 HTML，任何静态托管或本地双击即可放映，不反向依赖本包；改稿只动产物，不动底盘源码。
- **与枚举式禁令清单的区别**：三层是推导链（版面率第一性 → 推出字号 → 推出秩序，每条规则可回溯上层原理），配 token 强制与闭环机验（§1.2 版率口径）双保险；枚举清单只枚举症状，覆盖有洞、无推导链可校，且不测欠填。
