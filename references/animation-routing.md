# Animation Routing — 动画自动路由表（阶段 6 生成时查，不问客户）

> **原则（2026-10-21 维护者立）**：动画按 PPT 演讲类型与氛围自动配置，**不逐个问客户**。
> 生成端读本表 → 给元素挂类名 → 底盘自动执行。所有动画零 JS 配置、类名即生效。
> reduced-motion 用户全部自动降级静态（底盘兜底，无需处理）。

## 〇、主题动画开窗

封面/收尾/仪式页的动画**不锁基础套餐三选一**——本表类名库是框架起点，主题需要时可按主题即兴创作适合主题的动画（封面仪式动效、主题装置联动动效、主题化入场编排）。只有底线、没有菜单：

1. **纯 CSS 实现**（keyframes/transition，页内样式）：禁外部动画库。字体特效**点名制**：默认不加，用户点名才上——点名后按所用特效库自带的编号索引取参数（如开源项目 colorion-text-effects 的 `global.css` 注释编号），把对应 keyframes 内联进页内样式，挂 deck token 换肤；本包不内置字体特效库，也不引外链。
2. **代码动画不放权**：逐页手写的 JS 机制动画仍走 anim-recipes 三问闸门（只讲过程/机制/因果），此窗不开。
3. 三层收敛照管：命中正式汇报/打印分发/文字型等收敛信号，即兴动画随整包降档/归零。
4. reduced-motion 必须自带降级：即兴 keyframes 要写 `@media (prefers-reduced-motion: reduce)` 静态终态（底盘兜底只覆盖内置类名体系）。
5. 时长硬顶 4s；同页动画焦点唯一；入场节奏并入 `--d` 延迟编排档（不另起节奏）。
6. 阶段 5 预览随风格一起给人过目——动不动、怎么动，人拍板。

## 零、三层收敛规则（客户不说也要判——2026-10-21 维护者立）

**① 默认档 = 克制**（客户什么都不说的安全兜底）：只配功能性动画——`.rv` 入场分层 + 图表生长 + 数字滚动。帮读者看清内容，不是炫技；打印/PDF 也稳。

**② 收敛信号 = 自动降档**（客户没说"不要动画"，但语境里有线索）。命中任一 → 降到最小（只保 `.rv`，甚至整包装配走 `--no-effects`）：
- 客户原话出现："给领导汇报 / 正式评审 / 严肃场合 / 法务 / 财务 / 打印分发 / 主要发 PDF"
- 阶段 1 选**文字内容型**；阶段 5 选 **B1/B2 亮色池**
- **代码动画配额直接归零**（最贵可视化第一个砍，机制页转静态图示）

**③ 放开信号 = 才上炫技件**：客户说"产品发布会 / 科技秀 / 内部分享嗨一点 / 教学演示"，或阶段 5 选 A1/A2 里带科技签名的预设（Terminal Green / MongoDB / 8-Bit Orbit）→ 解锁 neon-glow、粒子、zoom-pop、step 密集叙事。

**告知不询问**：阶段 2 资料摘要尾部带一行「本 deck 动画节奏：克制档（正式汇报向）」——是通知不是问题，客户有意见自然提。

**代码动画**（机制演示，逐页手写）：不走本表类名体系——判定/配额/写法见 [anim-recipes.md](anim-recipes.md)，收敛联动见上②。

## 一、按内容侧重（阶段 1 的答案）定基础套餐

| 内容侧重 | 基础套餐 | 说明 |
|---|---|---|
| 数据驱动 | `.rv` 分层入场 + 图表生长（.bar/.line/.dot）+ **数字滚动**（自动命中） | 数据是主角，滚动+生长强调量级 |
| 平衡型（默认） | `.rv` 分层入场 + 图表生长 + 数字滚动 | 同上，节奏放缓（--d 间隔拉大 120ms 档） |
| 文字内容 | `.rv` 分层入场；关键词句可点名单用 `.rise-in` | 少即是多，禁满页花活 |
| 演讲演示型 | `.rv` + 数字滚动 + **step 叙事**（金句页/结论页逐条揭示） | 大字少文靠节奏感 |

## 二、按氛围（阶段 5 的 2×2 四池答案）定风格件

| 氛围池 | 追加 | 禁用 |
|---|---|---|
| A1 冲击暗色 | 封面 `.anim-scale` 缩放弹入；焦点数字 `.zoom-pop` | 粒子（无预设默认可用） |
| A2 沉静暗色 | 封面 `.anim-blur` 模糊到清晰；`.neon-glow` 点名单用 | 粒子（同上） |
| 科技签名预设（Terminal Green / MongoDB / 8-Bit Orbit 点名时） | `.bg-grid` 网格；`.neon-glow`；粒子需过 anim-recipes 三问闸门现写 | — |
| B1 纸感编辑 | 封面默认 `.rv` 淡入上滑即可；节奏放缓（--d 160ms 档） | 禁粒子/霓虹/网格 |
| B2 清爽现代 | 封面默认 `.rv` 柔和淡入；节奏 100-120ms 档 | 禁粒子/霓虹/网格（排版红线区） |

> 上表封面动画为基础套餐；主题需要更贴合的仪式动效时按「〇、主题动画开窗」即兴创作，底线六条不松。

## 三、点名单用库（任何类型，用户点名才加）

| 类名 | 效果 | 场景 |
|---|---|---|
| `.typewriter` | 逐字打字机（70ms/字） | 代码展示、关键引述 |
| `.step` / `.step.impact` | 点击逐步揭示 / 焦点数字弹入 | 叙事页、结论压轴 |
| `.spot-group` | 聚光式 step（**按需件**，客户点名才加）：组容器挂类，子项自动成聚光序列，讲到谁亮谁（其余退后 0.3）；`data-spot="1"` 单点模式 | 客户明确要求逐块讲/单板块强调的页 |
| `.tilt-card` | 3D 悬停倾斜 | 品牌风卡片（Apple/Stripe 类预设） |
| `.zoom-pop` | 弹性缩放 0.6→1.04→1 | 焦点数字冲击 |
| `.rise-in` | 升起+去模糊 | 金句质感 |
| `.geo-float` | 浮动模糊几何（absolute 定位摆件） | 科技封面装饰 |

## 四、step 叙事纪律（承 v1「附近页」事故教训）

- **同类正文组首条不挂 step**——翻到该页至少一条正文可见，禁「翻到即空页」
- 收尾金句/结论框挂 step 且排最后：先展开论据、最后收结论
- 频率指南：10 页 deck 用 2-3 页（焦点数字页+结论页），不是每页都要
- 交互自动接管：点击/翻页键先亮 step，全亮完才翻页；左向逆序收起；离开页面自动重置

**两种 step 模式（禁同页混用）**：
- **依次揭示（`.step`）**=内容逐个出现，适合论述点逐抛、结论压轴
- **聚光式（`.spot-group`，10-22 降为按需件）**=全组始终可见，当前项全亮、其余退后（opacity .3）——**仅当客户明确要求讲述编排时配置**（"我要逐块讲"/"帮我突出某板块"），生成端禁自动添加（推断不出讲述意图）。节奏：初始全亮 → 点按逐项聚光 → **末项聚光后即放行翻页**（软拦截无收束态）；单点模式 `data-spot="1"`。**纪律：组直接子项不挂 `.rv`**。原理与裁定见 [focus-judgment.md](focus-judgment.md) §二「动态两件·聚光式」

## 五、入场节奏参数（--d 延迟编排，氛围联动的唯一通道）

- 快节奏（A1 冲击暗色 + 科技签名单用）：首件 80ms 起，逐件 +80ms
- 标准（A2 沉静暗色 / B2 清爽现代）：首件 100ms 起，逐件 +100-120ms
- 缓慢（B1 纸感编辑）：首件 150ms 起，逐件 +160ms，仪式位可到 400ms
- 同页 ≤6 个延迟档；超过=砍分层，不排队（防末件等 1s+）
