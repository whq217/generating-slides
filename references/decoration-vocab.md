# 装饰层词汇库（.deco）——2026-10-23 立，demo-deck 五页验证后入盘

> 真源：本文件（词汇与纪律）。容器/词条 CSS 在底盘（core.css 骨架区 + effects.css 装饰章节）。
> 适配：frontend-slides 设计系统移植的"表现层"落点——判定权（版式/密度/槽位）仍归 layout-rules-v2，装饰只挂在槽位之下。

## 一、两条铁律（2026-10-23 立，违者即形态乱/串色）

1. **颜色一锅汤**：一套产物只许一个色调家族——底/墨/灰/装饰全部从同一母色系生（`--deco-tint` 承载，默认 = `--accent`）。封面可以同族做浓，内页同族做淡，**永不引入第二家族**。语义色 `--warn` 只落内容（数字/文字），禁进装饰。
2. **装饰一套词**：全片同一形态语言。签名词汇全片贯穿（同一形态，浓度不同），装置只在封面/收尾按固定规律出现，**禁中间内容页乱入、禁每页换形态**。

## 二、五条技术底线（不管哪个池、preset 还是即兴，都管）

1. 装饰只进 `.deco` 容器（`position:absolute; inset:0; pointer-events:none; z-index:0`），内容必须包 `.content`（z:1 永压装饰）。z-index:-1 替代方案已实测不可行（stage transform 下装饰被 body 背景吃掉）。
2. 装饰颜色只吃 `var()` 链 + `color-mix` 派生，**禁写死 hex**（verify-consistency D-2 同口径）。
3. 装饰不压文字层上方，但**参与构图平衡**——设计上算数，版率上不算数（探针已排除 `.deco`）。
4. 一页装饰 ≤2 件。
5. 意图三选一，说不出 = 凑数，撤：**主题隐喻 / 构图平衡 / 语义强调**。

## 三、浓淡体系（"封面浓、内页淡、首尾呼应"）

| 挂法 | 形态 | 用在 |
|---|---|---|
| `.deco`（默认） | 签名全浓度 | 封面 / 关键仪式页 |
| `.deco.dim` | atmos/grid/scan 降浓度（2026-10-24 校准：grid/scan 基础 12%/10% 不叠 opacity，dim 档 ×.55——原 dim 档 5%×.3=1.5% 有效在深底 1.03:1 投影隐身，实测 bug；dim 的 opacity 是**覆盖**不是叠乘） | 全部内容页 |
| `.deco.soft` | 主题装置淡版 | 收尾页（与封面装置呼应） |

典型成片配方：封面 `deco`（atmos+grid，可加主题装置）→ 内容页 `deco dim`（atmos+grid 同款）→ 收尾 `deco dim soft`（装置淡版呼应）。

## 四、词条体系（2026-10-23 起：封闭菜单 → 基础词条 + 主题装置开窗）

### 基础词条（effects.css 已内置，生成时按配方选配）

| 词条 | 形态 | 意图标签 | 说明 |
|---|---|---|---|
| `.atmos` | 明暗渐变（左上微亮→右下渐暗 + 两团极淡 tint） | 构图平衡 | 家族底，全片主签名首选；位置/尺寸走 `--deco-x/y/size` |
| `.grid` | 技术网格 | 主题隐喻 | 产业/数据感测距网；`--deco-cell/line` 控制密度 |
| `.scan` | 横纹扫描线纹理 | 主题隐喻 | 克制度最高的纹理底，监测/实验类主题 |
| `.sweep` | 动效扫描横光带（12s 巡扫） | 主题隐喻 | 动效签名；reduced-motion 自动降为静线 |

> `.device`（柱阵装置，8 根渐变立柱）2026-10-23 废除，生成时禁再配；需要立式装置走「主题装置」开窗现场定制参数（根数/密度/高度序列/透明度层次/尺度按主题调，预制固定参数必平庸）。

> `.band`（右缘 14px 竖向色带）2026-10-23 废除，生成时禁再配。

### 主题装置（开窗）

主题需要而基础词条覆盖不了的形态（竖条森林、等高线、点阵、电路、光锥、经纬线……），**可即兴发明**，与基础词条同权。只有纪律、没有菜单：

1. 技术底线全守：只进 `.deco` 容器、颜色只吃 var 链/color-mix、一锅汤、一页 ≤2 件、意图三选一说得出来。
2. 可当主签名全片贯穿（同形态不同浓度），也可当装置只进封面/收尾（浓淡体系不变：封面浓 / 内容 dim / 收尾 soft）。
3. 纯 CSS 实现（伪元素/渐变/shadow），禁外部图片；动效走 anim-runtime，reduced-motion 自动降级。
4. 生成后照常过机验（探针排除 `.deco` 的口径不变）。
5. 阶段 5 预览只管风格、不含装置——装置口径以 §五 为准（默认必做、阶段 6 首版即带、机验 #15 拦截；2026-10-24 起两节统一，浓淡微调仍人拍板）。
6. **版面规范零松动**：预设模板只是框架，设计自由只在装饰形态与配色演绎；版面率→字号→秩序三约束与机验标准一个都不许越。

基础词条新增加固有流程不变：先填四列（元素/容器/token 名/机验归属），任一列填不出 = 不许搬（迁移协议）。

## 五、封面构图总纲（2026-10-24 立——AI投毒封面实证 + NEV demo 验证入册）

**封面构图 = 标题 + 数字条 + 装置 + 装饰，同场经营，构图问题自裁决。**

- **四格是入场名单，不是必点清单**：必选 = 标题 + 装饰主签名；数字条有硬数字才进（无数字合法）；**装置 = 默认经营项**（生成必给方案，"提了才做"= 违规——治"许可不执行"，平庸交卷的代价从零变违规）
- **硬约束：封面必须有"第一视觉事件"，由数字或装置承担**——纯大标题不算数（标题升档只是让位/退档机制，不构成视觉事件）
- **规则模糊处，默认取克制侧**（立法总原则）：穷举不了的判断一律向克制侧解释（静态、低浓度、基础几何、说不出指纹就收着做）；上限靠开窗留给强模型，不把底线往上挪——底线挪高一格，弱模型够不着就造假应付，更丑
- **义务管动作，开窗管形态**：默认的只是"必须尝试"；形态不设菜单，清单所列是已验证例子，发明新形态同等合法，守三条纪律：挂 `.dv-` 标记、浓度预算、说得出来。默认形态给弱模型兜底（照做及格），自由形态给强模型抬上限（规则不封顶）
- **动画仅当客户明确要求才做，默认一律静态装置**（2026-10-24 一句话钉死）。客户要求做了，才附加两条检查：静帧站得住 + 逐态检查（起点/常态/终点各自截帧均为合格封面）+ reduced-motion 降级

### 5.1 hook 判定（流程第一步）

hook 是封面里的一个"位"，不是标题的一种"类型"。先判标题归属：

| 场景 | 标题格 | hook 落位 |
|---|---|---|
| 用户标题已是钩子/主张句 | 直接用 | 标题格 |
| 用户标题是话题容器（"XX 战略汇报"） | **一字不动** | 迁移到装置/副题/数字条格 |
| 用户未定标题 | 封面标题 = 全片第一个钩子句（C 档悬念式 / A·B 档主张式） | 标题格 |

- **管道**：候选取自阶段 3-4 已挖出的焦点池与钩子池，禁封面阶段现场另起炉灶；挖不出 = 阶段 3 的病（content-optimization §3.7 兜底）
- hook 五来源：最强**主张 / 隐喻 / 数字 / 时刻 / 冲突**；巨型数字必配口径注（"2分钟"必带"从发布到被采纳"），钩子四约束见 title-copy-types §4

### 5.2 装置（默认 = 排版装置）

| 族 | 形态 | 状态 |
|---|---|---|
| **排版装置** | 内核：巨型数字/关键词升格为第一视觉事件 + 口径注（普适）；外衣：编辑语法跟风格语域——大报=报眉/时间戳/通栏线、终端=提示符/版本号、工程=标注框/编号角标、档案=编号章/封条、瑞士=超大坐标字，**禁跨语域混用**；概念词视觉化（关键词大字 + 主题强绑定图形/字形变形，无硬数字题材替位；通用图标拼贴禁入） | **过验，默认路径** |
| 图形装置 | 抽象母题 × 动效 | **未过验，挂账**——客户点名或一整套主题指纹才碰（重启条件见《封面构图规则稿-2026-10-24》§七，内部稿不在包内，分发后以本表状态行为准） |
| 装饰词条 | atmos/grid/scan/sweep | 氛围底，全片浓度递变不变 |

- 装置挂 `.dv-` 前缀类名或 `data-device` 属性——给机验递钩子，无标记视同没做；装置落 `.content` 内**不进 `.deco` 容器**（进容器会被 #15c 数成第 3 件装饰超限、还被探针排除版率）
- **机验只验标记存在性，验不了装置是否成立**（2026-10-24 审核实测：空 `.dv-` 标记可绕过 #15a——标记在、装置烂，闸不拦，人把关）；合格参照 = `samples/good/chassis.html` 封面（stamp 走 176px 焦点数字档 + 口径注 + 标题退档 110，字号全走 token 不破 check-deck 档位）
- **装置-标题两翼配重**：装置版面感知占有率与标题块相当（0.5-1 带）；感知占比 = 实体锚点 + 被锚点收编的晕染领地（光晕单独 = 留白不记账，挂实体才成领地）；散布禁越入标题区

### 5.3 数字条双形态

- **底部 metrics 条**：slide 挂 `.has-metrics` + `.cover-metrics`（2-4 组 `.cm`：`.cm-v` 大数 + `.cm-l` 标签），三段式铁律：标题块中偏上 + 中部呼吸带 + 数字条上提贴底，**数字条与纯垂直居中禁混用**（实测重心偏下、顶部空）。风险数字挂 `.cm-v.wr`（warn 语义，与内页 `.yy.warn` 同一语言）。数字参与版率（非装饰）
- **stamp 主视觉**：巨型数字升格为封面第一视觉事件（**≤176px** 焦点数字上限档，参照 `samples/good/chassis.html` 封面；AI投毒标本 228→104 是退档教训、不是照抄值——写 228 会被 check-deck 字号档位判红）；唯一焦点互斥——stamp 上位则标题退档让位（140→110 式），配口径注与轴线（编辑语法）

### 5.4 四步流程（义务制，零新增交互）

```
① 挖 hook —— 判标题归属（5.1 判定树），定 hook 落位
② 选装置 —— 排版装置默认在案，最多两案，挂 .dv- 标记
③ 同场经营 —— 唯一焦点互斥（数字/装置当主角 → 标题退档）；
   两翼配重；三段式铁律（has-metrics 时）；装饰可见度不够调浓不删
④ 排版留到最后 —— 阶段 5 预览只管风格（封面不排版不装置，维持现状）；
   阶段 6 生成第一版即带装置交付；不满意 → 迭代改稿改哪页哪页
```

交互成本零新增：用户感知不变；纪律关归机验（verify-consistency 封面断言：视觉事件三选一——stamp 级数字 / .has-metrics+.cover-metrics / `.dv-` 装置标记（图形/排版同权，机验不区分），三项全缺 = 平庸封面 exit 1），人只把审美关。

## 六、token 与开口子

- `--deco-tint/x/y/size/cell/line`：装饰专用（core.css :root）。换风格只改这些 + 五件套，词汇零改动。
- `--radius-card` / `--shadow-card`：默认 `0px`/`none`（外观与无圆角无阴影完全一致）。风格配方开启 = 给 `.card-box` 挂 `.lift`（14px 圆角 + 投影，品牌卡场景；非品牌风格禁用）。**token 外仍禁渐变/阴影/圆角**。
- `--warn`：语义辅助色。**无机械派生规则**——风格配方按对主题色的理解指定（如青主调配琥珀黄），须写一句配色理由；未指定时退回 accent（= 无第二色）。

## 七、生成纪律（给生成时的自查）

1. 本页装饰是哪两个词？意图三选一说得出来吗？
2. 全片翻一遍：色调一个家族吗？形态一套词吗？装置只在首尾吗？
3. 用了 cover-metrics 的封面，slide 挂 .has-metrics 了吗？
4. 装饰 CSS 里有没有写死色值（应全 var/color-mix）？
5. 内容包 .content 了吗（否则装饰压字）？
6. **封面 hook 落位判了吗**（用户定稿一字不动/未定走钩子池，见 §5.1）？**封面带排版装置了吗**（stamp 巨数/编辑语法/概念词，挂 `.dv-` 标记）——纯大标题不算视觉事件，机验 #15 会拦？
7. **装置克制态还是发挥态**（说不出指纹就收着做；卡中间的"通用发挥"= 最丑区间，重做）？动画仅客户明确要求才做（默认一律静态）

## 九、踩坑记录（2026-10-23 实测）

- **CSS 注释里禁写 `xxx-*/yyy`**：`--radius-*/--shadow-*` 中的 `*/` 会提前闭合注释，垃圾文本吞掉后续规则（`:root` 整体失效、全片变量死、页面黑字透明底）。注释里 token 名用顿号隔开。
- **z-index:-1 方案不可行**：stage transform 建立 stacking context，装饰沉到 body 背景之下直接消失。必须 .content z:1 方案。
- **.content 会吃掉 slide 级 ritual 居中**：`.ritual { justify-content:center }` 作用于 .content（flex:1 拉满）无效，必须在 `.ritual .content` 上兑现——漏掉则封面塌顶（内容全堆顶部）。
- 纯 CSS 装饰（无文本、非 img/svg）探针天然不计；探针排除是给 SVG 装置/带文字装饰兜底。
