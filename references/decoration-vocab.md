# 装饰层词汇库（.deco）——2026-10-23 立，demo-deck 五页验证后入盘

> 真源：本文件（词汇与纪律）。容器/词条 CSS 在底盘（core.css 骨架区 + effects.css 装饰章节）。
> 适配：frontend-slides 设计系统移植的"表现层"落点——判定权（版式/密度/槽位）仍归 layout-rules-v2，装饰只挂在槽位之下。

## 一、两条铁律（2026-10-23 立，违者即形态乱/串色）

1. **颜色一锅汤**：一套产物只许一个色调家族——底/墨/灰/装饰全部从同一母色系生（`--deco-tint` 承载，默认 = `--accent`）。封面可以同族做浓，内页同族做淡，**永不引入第二家族**。语义色 `--warn` 只落内容（数字/文字），禁进装饰。
2. **装饰一套词**：全片同一形态语言。签名词汇全片贯穿（同一形态，浓度不同），装置只在封面/收尾按固定规律出现，**禁中间内容页乱入、禁每页换形态**。

## 二、五条技术底线（不管哪个池、preset 还是即兴，都管）

1. 装饰只进 `.deco` 容器（`position:absolute; inset:0; pointer-events:none; z-index:0`），内容必须包 `.content`（z:1 永压装饰）。z-index:-1 替代方案已实测不可行（stage transform 下装饰被 body 背景吃掉）。
2. 装饰颜色只吃 `var()` 链 + `color-mix` 派生，**禁写死 hex**（verify-consistency D-2 同口径）。
3. 装饰不压文字层上方，但**参与构图平衡**——设计上算数，版率上不算数（探针已排除 `.deco`）。
4. 一页装饰 ≤2 件。
5. 意图三选一，说不出 = 凑数，撤：**主题隐喻 / 构图平衡 / 语义强调**。

## 三、浓淡体系（"封面浓、内页淡、首尾呼应"）

| 挂法 | 形态 | 用在 |
|---|---|---|
| `.deco`（默认） | 签名全浓度 | 封面 / 关键仪式页 |
| `.deco.dim` | atmos/grid 降浓度（grid .55→.3） | 全部内容页 |
| `.deco.soft` | 主题装置淡版 | 收尾页（与封面装置呼应） |

典型成片配方：封面 `deco`（atmos+grid，可加主题装置）→ 内容页 `deco dim`（atmos+grid 同款）→ 收尾 `deco dim soft`（装置淡版呼应）。

## 四、词条体系（2026-10-23 起：封闭菜单 → 基础词条 + 主题装置开窗）

### 基础词条（effects.css 已内置，生成时按配方选配）

| 词条 | 形态 | 意图标签 | 说明 |
|---|---|---|---|
| `.atmos` | 明暗渐变（左上微亮→右下渐暗 + 两团极淡 tint） | 构图平衡 | 家族底，全片主签名首选；位置/尺寸走 `--deco-x/y/size` |
| `.grid` | 技术网格 | 主题隐喻 | 产业/数据感测距网；`--deco-cell/line` 控制密度 |
| `.scan` | 横纹扫描线纹理 | 主题隐喻 | 克制度最高的纹理底，监测/实验类主题 |
| `.sweep` | 动效扫描横光带（12s 巡扫） | 主题隐喻 | 动效签名；reduced-motion 自动降为静线 |

> `.device`（柱阵装置，8 根渐变立柱）2026-10-23 废除，生成时禁再配；需要立式装置走「主题装置」开窗现场定制参数（根数/密度/高度序列/透明度层次/尺度按主题调，预制固定参数必平庸）。

> `.band`（右缘 14px 竖向色带）2026-10-23 废除，生成时禁再配。

### 主题装置（开窗）

主题需要而基础词条覆盖不了的形态（竖条森林、等高线、点阵、电路、光锥、经纬线……），**可即兴发明**，与基础词条同权。只有纪律、没有菜单：

1. 技术底线全守：只进 `.deco` 容器、颜色只吃 var 链/color-mix、一锅汤、一页 ≤2 件、意图三选一说得出来。
2. 可当主签名全片贯穿（同形态不同浓度），也可当装置只进封面/收尾（浓淡体系不变：封面浓 / 内容 dim / 收尾 soft）。
3. 纯 CSS 实现（伪元素/渐变/shadow），禁外部图片；动效走 anim-runtime，reduced-motion 自动降级。
4. 生成后照常过机验（探针排除 `.deco` 的口径不变）。
5. 阶段 5 预览随风格一起给人过目——装不装、浓不浓，人拍板。
6. **版面规范零松动**：预设模板只是框架，设计自由只在装饰形态与配色演绎；版面率→字号→秩序三约束与机验标准一个都不许越。

基础词条新增加固有流程不变：先填四列（元素/容器/token 名/机验归属），任一列填不出 = 不许搬（迁移协议）。

## 五、数据型封面（cover-metrics 变体）

- **判定**：内容有强数字（数据汇报型）→ 用数字条；叙事型 → 纯仪式位。判定权在槽位树。
- **结构**：slide 挂 `.has-metrics` + 底部 `.cover-metrics`（2-4 组 `.cm`：`.cm-v` 大数 + `.cm-l` 标签）。
- **三段式铁律**：标题块中偏上（`.has-metrics .content` 已带）+ 中部呼吸带 + 数字条上提贴底。**数字条与纯垂直居中禁混用**（实测重心偏下、顶部空）。
- 风险数字挂 `.cm-v.wr`（warn 语义，与内页 `.yy.warn` 同一语言）。数字参与版率（非装饰）。

## 六、token 与开口子

- `--deco-tint/x/y/size/cell/line`：装饰专用（core.css :root）。换风格只改这些 + 五件套，词汇零改动。
- `--radius-card` / `--shadow-card`：默认 `0px`/`none`（外观与无圆角无阴影完全一致）。风格配方开启 = 给 `.card-box` 挂 `.lift`（14px 圆角 + 投影，品牌卡场景；非品牌风格禁用）。**token 外仍禁渐变/阴影/圆角**。
- `--warn`：语义辅助色。**无机械派生规则**——风格配方按对主题色的理解指定（如青主调配琥珀黄），须写一句配色理由；未指定时退回 accent（= 无第二色）。

## 七、生成纪律（给生成时的自查）

## 九、踩坑记录（2026-10-23 实测）

- **CSS 注释里禁写 `xxx-*/yyy`**：`--radius-*/--shadow-*` 中的 `*/` 会提前闭合注释，垃圾文本吞掉后续规则（`:root` 整体失效、全片变量死、页面黑字透明底）。注释里 token 名用顿号隔开。
- **z-index:-1 方案不可行**：stage transform 建立 stacking context，装饰沉到 body 背景之下直接消失。必须 .content z:1 方案。
- **.content 会吃掉 slide 级 ritual 居中**：`.ritual { justify-content:center }` 作用于 .content（flex:1 拉满）无效，必须在 `.ritual .content` 上兑现——漏掉则封面塌顶（内容全堆顶部）。
- 纯 CSS 装饰（无文本、非 img/svg）探针天然不计；探针排除是给 SVG 装置/带文字装饰兜底。
