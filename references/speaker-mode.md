# 演讲者模式（底盘已内置，行为说明）

**状态**：v2 底盘 `chassis-v2.html` 已内置完整演讲者模式（interactions 件 `toggleSpeaker` + `buildPresenterWindow` + BroadcastChannel 同步），生成端**无需实现任何代码**，唯一必做项是把每页讲稿写进 `NOTES` 对象（见下）。

---

## 生成端唯一必做项：填充 NOTES

每页 3-5 条提词卡要点（不写逐字稿）写入产物 JS 的 `NOTES` 对象，键 = 对应 `<section class="slide">` 的 id：

```js
var NOTES = {
  "p3": ["先说结论：增速见顶", "数字 47% 停顿两秒", "对比去年 61%"],
  ...
};
```

S 演讲者窗口备注卡读此数据源。某页无备注 → 备注卡显示"（这一页还没有备注）"。

> N 提词面板已移除（2026-10-24）：主窗口是投屏，面板观众可见；提词职责归演讲者窗口备注卡。

## 入口

- **S 键** 切换 / 再按聚焦已开窗口
- 右下角浮动按钮（显示器图标，`#spkToggle`）

## 独立浏览器窗口（非页面内弹窗）

支持双屏：演讲者窗口放自己屏幕，观众视图放投影仪。窗口 1280×820，内含 4 张卡片：

| 卡片 | 内容 | 说明 |
|------|------|------|
| **当前页** | iframe 像素级预览（1920×1080 等比缩放） | 和观众看到的完全一致 |
| **下一页** | iframe 像素级预览 | 提前知道下一页长什么样 |
| **备注（可编辑）** | 逐条显示 NOTES 要点，contentEditable | 编辑后实时回写主文档 `NOTES` 并刷新提词面板 |
| **计时器** | 大字计时 + 页码 + 重置/启停 | — |

卡片可拖拽（标题栏）、可缩放（右下角把手），布局（位置/尺寸）自动存 localStorage（键 `slides-presenter-layout:` + 路径），刷新不丢失；底部有重置布局按钮。

> 只持久化卡片布局，与「编辑内容不自动从 localStorage 恢复」规则不冲突——布局可以恢复，幻灯片内容不恢复旧版本。

## BroadcastChannel 双窗口同步

- 观众翻页 → 演讲者窗口自动更新
- 演讲者窗口翻页 → 观众视图自动更新
- 备注编辑经频道消息（`notes-update`）回写主文档

频道名 `slides-presenter-` + `location.pathname`，同源同路径的窗口自动互通。
