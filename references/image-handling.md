# 封面图处理（图片唯一出口）

> 版本：2026-10-20 v2（同日维护者拍板：内容页图文布局 H/IC 全族 8 种移除，图片仅用于封面；后续接入的 AI 生图 API 也只做封面生图）
> 定位：整个 deck 只有封面可以有图片——全出血背景、或「左文右图」变体的右图位。**内容页一律无图**：图示需求用图表（chart-recipes）/ SVG 图形 / CSS 渐变表达。

## 封面图来源（二选一）

1. **用户提供**：仅接受封面用途；WebP（体积最小）/ JPG（通用）优先，需透明通道用 PNG；转 base64 内联进 HTML（保持单文件）——bash：`base64 -w0 图.png`；PowerShell（无 bash 时）：`[Convert]::ToBase64String([IO.File]::ReadAllBytes("图.png"))`。**单张 ≤500KB**（base64 后约 670KB），超过提示用户压缩
2. **AI 生图 API（待接入占位）**：只对封面生图，不生成内容页插图。规格建议：
   - 全出血背景：16:9 横版（1920×1080），基调跟随所选主题（暗色/亮色/品牌色）
   - 右图位：3:4 竖版（如 960×1280）
   - 风格跟随阶段 5 选定的主题预设；生成后同样 base64 内联
   - **接入前本口子留空：不搜图、不占位假图、不编造图片 URL**——封面退回 CSS 渐变/SVG 背景路径

## 嵌入规则

- 封面图容器一律 `<div>` + `background-image:url('data:image/webp;base64,...')` + `background-size:cover`，**不用 `<img>` 标签**（背景方案裁剪与遮罩控制更稳）
- `background-position` 手动设置：竖图偏上（如 `center 20%`）防裁头，横图居中
- 全出血背景需：`position:absolute` 铺满 + 半透明遮罩层 + 白色文字防御
- **图上小字（badge/标签级）≠ 整页遮罩路线**：小字垫**品牌色实色圆角小块**（非半透明，抗噪彻底），尺寸刚好包住——双作用与尺寸纪律的真源在 [focus-judgment.md](focus-judgment.md) §二「结构辅助·衬底双功能」；图上边注/角落小字加深文字色或小衬底二选一
- SVG 主题图形可直接内联 SVG 代码，不走 base64

## 无图默认路径

用户未提供图、且 AI 生图 API 未接入 → 封面用 CSS 渐变/SVG 生成背景（全出血/左文右图各变体均有渐变版），不主动搜图。

## 已移除能力（防模型凭记忆复活）

内容页图文布局（H-1/H-2、IC-1~IC-4C 共 8 种）已于 2026-10-20 随 v1 布局库（layout-patterns.md，现已移出技能包）一并移除。内容页出现"想配图"的需求时改走槽位判定树：数据 → 焦点数字 / metric 槽位、趋势构成排行 → 图表（chart-recipes）、过程/机制/流向 → 图示（diagram-patterns）、并列概念 → 双栏或行组——**用数据和图形表达，不用图片**。
